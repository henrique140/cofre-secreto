# Cofre Secreto

Jogo de adivinhação de senha com interface visual em HTML, CSS e JavaScript.

## Como abrir

1. Abra a pasta do projeto.
2. Dê duplo clique em `index.html` ou rode um servidor local.

## Como rodar localmente

```bash
cd cofre-secreto
python -m http.server 8000
```

Depois acesse:

http://localhost:8000

## Publicar no GitHub

1. Crie um repositório no GitHub.
2. Rode:

```bash
git init
git add .
git commit -m "Primeiro commit"
git branch -M main
git remote add origin <URL_DO_REPOSITORIO>
git push -u origin main
```

## Arquivos

- `index.html` – interface e lógica do jogo
- `README.md` – instruções do projeto
